# Evgeniy Apple — первая версия

Локальный демонстрационный MVP магазина:

- улучшенный hero-ролик `assets/hero-enhanced.mp4` (масштабирование Lanczos, лёгкая коррекция контраста/цвета и unsharp-фильтр);
- центральный экран «Добро пожаловать» и 3D-кнопка «В магазин»;
- параллакс-галерея iPhone при прокрутке и tilt-эффект карточек;
- каталог с фильтрами, модальным просмотром и корзиной;
- заказ через Telegram: состав заказа автоматически копируется в буфер обмена, затем открывается указанная Telegram-ссылка;
- Instagram и Telegram в подвале;
- приватная страница `#admin` с паролем из задачи, добавлением/редактированием/удалением товаров в localStorage.

Это фронтенд-MVP: данные каталога и пароль хранятся в браузере, поэтому для боевого магазина админку нужно перенести на серверную авторизацию и базу данных.
